Parameter file upgrade check

Drop a .params file here or click to choose one

The file is read in this page only. Nothing is uploaded and the page makes no network requests.

When you need this

When PX4 upgrades the parameters stored on a vehicle, it converts some renamed parameters itself. It does not do that when you load a saved file in QGroundControl: values under old names are dropped. Check a file before you load it onto a vehicle that runs the new release, for example after a parameter reset, on a new or replaced flight controller, or to set up several vehicles from one file.

  1. Drop the file saved on the old release here (QGroundControl: Parameters, Tools, Save to file).
  2. Go through the lists below and download the corrected file.
  3. On the upgraded vehicle, load it (Parameters, Tools, Load from file), review the changes QGroundControl shows, and reboot.
